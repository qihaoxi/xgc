# 17 — 算法插件注册与运行时切换

> "灵活切换各种 GC 算法"是本框架的核心卖点。本文件定义算法如何注册、发现、选择、协商能力,以及编译时切换与运行时切换两种模式的完整机制。

---

## 1. 两种切换模式

| 模式 | 时机 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| **编译时切换** | `cmake -DGC_ALGORITHM=xxx` | 零运行时开销、可裁剪代码体积 | 一个二进制只含一个算法 | 嵌入式、产品发布 |
| **运行时切换** | `gc_runtime_create(cfg, algo, hooks)` | 一个二进制含多算法、可对比测试 | 略大体积、间接调用开销 | 测试、benchmark、需要多算法共存 |

**当前实现**:两种都支持。`xgc_algorithm_xxx()` 工厂函数在运行时返回 vtable;CMake 的 `GC_ALGORITHM` 控制哪些算法目录被编译进来。

---

## 2. 编译时切换的完整机制

### 2.1 CMake 选择算法目录

```cmake
# 只编译选中算法的源文件
file(GLOB_RECURSE XGC_ALGO_SOURCES CONFIGURE_DEPENDS
    ${XGC_SOURCE_ROOT}/algo/${GC_ALGORITHM}/*.c)
```

### 2.2 默认算法解析

每个算法目录的入口文件提供 `xgc_default_algorithm()`。但多算法编译时只能有一个 `xgc_default_algorithm` 定义 → **链接冲突**。

**解决方案**:`xgc_default_algorithm()` 的定义用条件编译隔离:

```c
/* src/core/default_algo.c（新建，唯一的 default 定义处） */
#include "gc_internal.h"

const gc_algorithm_vtable* xgc_default_algorithm(void) {
#if defined(XGC_DEFAULT_MARKSWEEP)
    return xgc_algorithm_marksweep_stw();
#elif defined(XGC_DEFAULT_GEN_COPY_MS)
    return xgc_algorithm_gen_copy_ms();
#elif defined(XGC_DEFAULT_BACON_RAJAN)
    return xgc_algorithm_bacon_rajan();
#else
    return xgc_algorithm_gen_copy_ms();  /* 兜底默认 */
#endif
}
```

```cmake
# CMakeLists.txt 根据 GC_ALGORITHM 设置默认宏
if (GC_ALGORITHM STREQUAL "marksweep")
    target_compile_definitions(xgc PRIVATE XGC_DEFAULT_MARKSWEEP)
elseif (GC_ALGORITHM STREQUAL "gen_copy_ms")
    target_compile_definitions(xgc PRIVATE XGC_DEFAULT_GEN_COPY_MS)
elseif (GC_ALGORITHM STREQUAL "bacon-rajan")
    target_compile_definitions(xgc PRIVATE XGC_DEFAULT_BACON_RAJAN)
endif()
```

> **重要约束**:算法入口文件中**不要**各自定义 `xgc_default_algorithm()`(会链接冲突)。统一由 `src/core/default_algo.c` 提供。各算法只提供 `xgc_algorithm_<name>()` 工厂。

## 3. 运行时多算法共存

### 3.1 全部算法编译进同一二进制

```cmake
option(GC_ALL_ALGORITHMS "编译所有算法以支持运行时切换" OFF)
if (GC_ALL_ALGORITHMS)
    file(GLOB_RECURSE XGC_ALGO_SOURCES CONFIGURE_DEPENDS
        ${XGC_SOURCE_ROOT}/algo/*/*.c)   # 注意:两层通配,所有算法
    target_compile_definitions(xgc PRIVATE GC_ALL_ALGORITHMS)
endif()
```

> 启用 `GC_ALL_ALGORITHMS` 时,各算法的 `xgc_default_algorithm` 必须全部移除(只保留 `src/core/default_algo.c` 的)。各算法目录只导出 `xgc_algorithm_<name>()`。

### 3.2 运行时选择

```c
/* 用户代码 */
const gc_algorithm_vtable* algo;
if (workload_is_short_lived)
    algo = xgc_algorithm_gen_copy_ms();
else if (need_deterministic_release)
    algo = xgc_algorithm_bacon_rajan();
else
    algo = xgc_algorithm_marksweep_stw();

gc_runtime* rt = gc_runtime_create(&cfg, algo, &hooks);
```

### 3.3 算法注册表(可选,用于按名字查找)

```c
/* include/xgc/gc_algorithm.h 增加 */
const gc_algorithm_vtable* xgc_algorithm_by_name(const char* name);

/* src/core/algo_registry.c（新建） */
typedef struct {
    const char* name;
    const gc_algorithm_vtable* (*factory)(void);
} gc_algo_entry;

static const gc_algo_entry GC_ALGO_REGISTRY[] = {
#if defined(GC_ALL_ALGORITHMS) || defined(XGC_DEFAULT_MARKSWEEP)
    { "marksweep",   xgc_algorithm_marksweep_stw },
#endif
#if defined(GC_ALL_ALGORITHMS) || defined(XGC_DEFAULT_GEN_COPY_MS)
    { "gen_copy_ms", xgc_algorithm_gen_copy_ms },
#endif
#if defined(GC_ALL_ALGORITHMS) || defined(XGC_DEFAULT_BACON_RAJAN)
    { "bacon-rajan", xgc_algorithm_bacon_rajan },
#endif
    { NULL, NULL }
};

const gc_algorithm_vtable* xgc_algorithm_by_name(const char* name) {
    if (!name) return NULL;
    for (const gc_algo_entry* e = GC_ALGO_REGISTRY; e->name; e++) {
        if (strcmp(e->name, name) == 0) return e->factory();
    }
    return NULL;
}
```

## 4. 能力协商(Capability Negotiation)

### 4.1 VM 查询算法能力

VM 可能依赖某些 GC 能力(如必须支持 moving 或必须支持即时析构)。在创建 runtime 前查询:

```c
const gc_algorithm_vtable* algo = xgc_algorithm_by_name("gen_copy_ms");
if (!algo) { /* 算法不可用 */ }

/* 检查 VM 需要的能力 */
if (vm_needs_deterministic_release && !algo->caps.provides_deterministic_release) {
    fprintf(stderr, "选中的算法不支持即时析构\n");
    /* 换一个算法或报错 */
}
if (vm_has_pinned_native_pointers && algo->caps.supports_moving) {
    /* moving 算法 + 裸指针 → 必须用 handle/pin 保护 */
}
```

### 4.2 能力矩阵(各算法声明)

| caps 字段 | marksweep | gen_copy_ms | bacon-rajan | gen_copy_compact | regional |
|-----------|:---------:|:-----------:|:-----------:|:----------------:|:--------:|
| supports_moving | 0 | 1 | 0 | 1 | 1 |
| supports_compaction | 0 | 0 | 0 | 1 | 1 |
| supports_generations | 0 | 1 | 0 | 1 | 1 |
| requires_write_barrier | 0 | 1 | 1 | 1 | 1 |
| requires_read_barrier | 0 | 0 | 0 | 0 | 1 |
| supports_concurrent_mark | 0 | 0 | 0 | 0 | 1 |
| supports_concurrent_relocate | 0 | 0 | 0 | 0 | 1 |
| provides_deterministic_release | 0 | 0 | 1 | 0 | 0 |

### 4.3 能力的语义契约

| 能力 | 为真时框架保证 | 为真时算法必须 |
|------|--------------|--------------|
| supports_moving | gc_load_ref 返回的指针可能变化,需用 handle 固定 | 实现 pin/unpin,collect 时更新所有 slot |
| requires_write_barrier | 所有 gc_store_ref 都调 write_barrier | 实现 write_barrier |
| requires_read_barrier | 所有 gc_load_ref 都调 read_barrier | 实现 read_barrier |
| provides_deterministic_release | 无环对象引用归零立即 finalize | write_barrier 中做 retain/release |
| supports_concurrent_mark | mark 与 mutator 并发 | 实现 SATB 或 incremental-update barrier |

## 5. 算法选择决策树(给 VM 开发者)

```
VM 大量持有裸 C 指针,不能容忍对象移动?
├── 是 → marksweep(非移动) 或 bacon-rajan(非移动 + 即时析构)
│        需要即时析构(文件句柄/socket)? → bacon-rajan
│        否 → marksweep
└── 否(可以接受对象移动)
     ├── 对象大多短命(典型脚本/编译器负载)? → gen_copy_ms
     ├── 长期运行需要消除碎片? → gen_copy_compact
     └── 大堆 + 低延迟要求(< 10ms 暂停)? → regional(并发)
```

## 6. 添加新算法的注册 Checklist

```
□ 1. src/algo/<name>/ 目录,实现 vtable + xgc_algorithm_<name>() 工厂
□ 2. include/xgc/gc_algorithm.h 声明 xgc_algorithm_<name>()
□ 3. 不要在算法文件中定义 xgc_default_algorithm()
□ 4. src/core/default_algo.c 增加 #elif 分支
□ 5. src/core/algo_registry.c 增加注册表条目
□ 6. CMakeLists.txt 的 GC_ALGORITHM STRINGS 增加选项 + 默认宏映射
□ 7. 正确声明 caps（与实际 vtable 函数指针一致,启动验证会检查）
□ 8. tests/test_<name>_smoke.c + cmake 条件注册
□ 9. 全算法回归通过 + ASan 零报错
```

## 7. 切换机制的测试

```c
/* tests/test_algo_switch_substrate.c（需 GC_ALL_ALGORITHMS） */
#ifdef GC_ALL_ALGORITHMS
int main(void) {
    /* 验证每个算法都能创建 runtime + 基本分配回收 */
    const char* names[] = { "marksweep", "gen_copy_ms", "bacon-rajan" };
    for (int i = 0; i < 3; i++) {
        const gc_algorithm_vtable* algo = xgc_algorithm_by_name(names[i]);
        assert(algo != NULL);
        assert(strcmp(algo->name, names[i]) == 0 ||
               strcmp(algo->name, "marksweep-stw") == 0);  /* 名字可能带后缀 */
        gc_config cfg; gc_config_init_default(&cfg);
        gc_vm_hooks hooks = {0};
        gc_runtime* rt = gc_runtime_create(&cfg, algo, &hooks);
        assert(rt != NULL);
        assert(gc_runtime_check_invariants(rt) == 1);
        gc_collect_full(rt);
        gc_runtime_destroy(rt);
    }
    /* 验证未知算法返回 NULL */
    assert(xgc_algorithm_by_name("nonexistent") == NULL);
    return EXIT_SUCCESS;
}
#else
int main(void) { return 0; }
#endif
```
