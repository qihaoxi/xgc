## Phase 1: card_table 性能优化

**目标**：把 `gc_card_table_find_entry` 从 O(n) 线性查找升级为 O(1) 哈希查找。

### Task 1.1: 引入简单开放寻址哈希表

**文件**：`src/core/card_table.c`

**改动**：
- 在 `gc_card_table` 结构中增加 `size_t hash_mask` 字段（表示 capacity 为 2^n）
- `entries` 数组改为按 `owner_base` 哈希定位
- `register_owner`：计算 `hash(owner_base)` → 线性探测空槽插入
- `find_entry`：`hash(owner_base)` → 线性探测查找
- `unregister_owner`：标记为 tombstone（`owner_base = 1`）
- 需要增加 `tombstone` 处理逻辑

**hash 函数**：
```c
static size_t gc_card_table_hash(uintptr_t key, size_t mask) {
    key ^= key >> 16;
    key *= 0x45d9f3b;
    key ^= key >> 16;
    return (size_t)(key & mask);
}
```

**验证**：
```bash
cmake --build build && ctest --test-dir build -R card_table
```

### Task 1.2: 更新 `gc_internal.h` 中的 `gc_card_table` 定义

**改动**：增加 `hash_mask` 字段。

### Task 1.3: 更新 invariants

**文件**：`src/core/invariants.c`

**改动**：`gc_card_table_check_invariants` 需要检查 `capacity` 是 2 的幂。

## Phase 4: rc-cycle 算法实现

**目标**：完整实现 Bacon-Rajan RC + Cycle Collector 作为算法插件。

### Task 4.1: 定义算法私有状态

**文件**：`src/algo/bacon-rajan/gc_alloc.c`

```c
typedef struct GcRcNode {
    gc_header*        obj;
    uint32_t          rc;        // 堆引用计数（栈不计数）
    uint32_t          gc_ref;    // trial deletion 工作计数
    uint8_t           color;     // BLACK/GRAY/WHITE/PURPLE
    uint8_t           in_purple; // 防重复加入
    struct GcRcNode*  next;      // 全对象链表
} GcRcNode;

typedef struct {
    GcRcNode*   objects;           // 全对象链表
    GcRcNode**  purple_buffer;     // 紫色缓冲区
    int         purple_count;
    int         purple_capacity;
} GcBaconRajanState;
```

### Task 4.2: 实现 `write_barrier`

**文件**：`src/algo/bacon-rajan/gc_assign.c`
