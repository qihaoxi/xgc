## 3. Core — 共享基础层（`src/core/`）

### `runtime.c`（360 行）

**职责**：运行时中枢。分发所有公共 API 到算法 vtable。

| 函数 | 行为 |
|------|------|
| `gc_runtime_apply_default_config` | 填充 cfg 零值为默认值 |
| `gc_config_init_default` | memset + apply_default |
| `gc_runtime_create` | calloc → copy cfg → validate contracts → init heap/worklist/barriers → algo->global_init |
| `gc_runtime_destroy` | 释放 handles → algo->global_destroy → barrier_destroy → free worklist → free rt |
| `gc_thread_attach` | calloc → algo->thread_init |
| `gc_thread_detach` | algo->thread_destroy → free |
| `gc_alloc_typed` | algo->alloc → 补充 obj 字段 → algo->post_alloc |
| `gc_store_ref` | *slot = new → algo->write_barrier |
| `gc_load_ref` | algo->read_barrier 或直接 *slot |
| `gc_collect_minor/major/full` | 委托 algo->collect_* → stats++ |
| `gc_handle_acquire/get/release` | 链表管理 + algo->pin/unpin |
| `gc_runtime_validate_contracts` | 验证 algo caps ↔ 函数指针一致性 |

### `reclaim.c`（20 行）

```c
void gc_reclaim_object(gc_runtime* rt, gc_header* obj) {
    if (obj->desc && obj->desc->finalize) obj->desc->finalize(obj);
    stats.total_allocated -= obj->size;
    free(obj);
}
```

## 4. 算法插件（`src/algo/`）

### `marksweep/ms.c`（308 行）

私有状态：`GcMsNode { obj, marked, next }` + `GcMarksweepState { objects }`

vtable caps：`moving=0, generations=0, write_barrier=0`

| 函数 | 行为 |
|------|------|
| `alloc` | calloc + 建 GcMsNode 挂到链表 |
| `collect_full` | mark(handles → roots → drain worklist) → sweep(链表删除+reclaim) |
| `write_barrier` | 空（不需要） |
| `pin/unpin` | 设/清 flags |

**完成度**：✅ 完整工作

---

### `gen_copy_ms/young_copy.c`（609 行）

私有状态：`GcGenCopyMsState { nursery_space, nursery_capacity, nursery_used, old_objects: GcGenOldNode*, forwarded: GcGenForward* }`

vtable caps：`moving=1, generations=1, write_barrier=1`

| 函数 | 行为 |
|------|------|
| `alloc` | 小对象 → nursery bump pointer；大/pinned → calloc + add_old_node + barrier_register |
| `write_barrier` | 如果 owner(old) 写入 new(young) → gc_barrier_mark_slot_dirty |
| `collect_minor` | handles→roots→dirty_cards→drain → finalize dead nursery → reset |
| `collect_full` | minor 先 → 再 mark+sweep old |
| `pin/unpin` | 设/清 flags |

**完成度**：✅ 完整工作
