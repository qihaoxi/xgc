# 12 — 统计、度量与 GC 调优

> 没有度量就没有优化。本文件定义 xgc 的统计收集机制和 GC 调优接口。

---

## 1. 统计数据结构

### 1.1 当前统计（已实现）

```c
typedef struct gc_stats {
    size_t total_allocated;     // 当前已分配字节数
    size_t peak_allocated;      // 历史峰值
    size_t minor_collections;   // minor GC 次数
    size_t major_collections;   // major GC 次数
    size_t full_collections;    // full GC 次数
} gc_stats;
```

### 1.2 需要扩展的统计（工业级必备）

```c
typedef struct gc_stats {
    // ── 分配 ──
    size_t total_allocated;
    size_t peak_allocated;
    size_t total_freed;
    size_t alloc_count;              // 分配次数
    size_t large_alloc_count;        // 大对象分配次数

    // ── 回收 ──
    size_t minor_collections;
    size_t major_collections;
    size_t full_collections;
    size_t objects_reclaimed;         // 回收对象数
    size_t bytes_reclaimed;           // 回收字节数
    size_t objects_promoted;          // 晋升对象数
    size_t bytes_promoted;            // 晋升字节数
    size_t objects_finalized;         // 调用了 finalizer 的对象数

    // ── 暂停 ──
    double last_pause_ms;             // 最近一次 GC 暂停时间
    double max_pause_ms;              // 历史最长暂停
    double total_pause_ms;            // 累计暂停时间

    // ── 堆 ──
    size_t heap_live_bytes;           // 上次 GC 后的存活字节数
    size_t nursery_survival_rate_pct; // 最近一次 minor GC 的存活率 (0-100)

    // ── 屏障 ──
    size_t barrier_store_count;       // gc_store_ref 调用次数
    size_t barrier_dirty_count;       // 实际标脏次数
    size_t cards_scanned;             // minor GC 扫描的 dirty card 数

    // ── 多线程 ──
    size_t stw_count;                 // STW 次数
    double stw_total_wait_ms;         // 等待所有线程到达 safepoint 的累计时间
} gc_stats;
```

## 3. GC 调优参数

### 3.1 `gc_config` 完整版

```c
typedef struct gc_config {
    // ── 水位线 ──
    size_t gc_threshold_soft;        // 建议限速
    size_t gc_threshold_hard;        // 强制 STW
    
    // ── 空间大小 ──
    size_t gc_young_space_size;      // nursery 大小（默认 4MB）
    size_t gc_region_size;           // region 粒度（默认 256KB）
    size_t gc_large_object_threshold; // 大对象阈值（默认 32KB）
    
    // ── 调优参数 ──
    size_t gc_tlab_size;             // TLAB 大小（默认 64KB）
    int    gc_target_pause_ms;       // 目标暂停时间（并发 GC 用）
    int    gc_growth_percent;        // 堆增长触发比例（类似 Go 的 GOGC）
    int    gc_promotion_age;         // 晋升年龄阈值（存活 N 轮 → 晋升）
    
    // ── 标志 ──
    uint32_t gc_flags;
    int      gc_debug_enable;
} gc_config;
```

### 3.2 运行时动态调参

```c
// 允许运行时修改部分参数
void gc_runtime_set_threshold_soft(gc_runtime* rt, size_t bytes);
void gc_runtime_set_threshold_hard(gc_runtime* rt, size_t bytes);
void gc_runtime_set_target_pause(gc_runtime* rt, int ms);
```

## 4. 背压（Backpressure）机制

### 4.1 三级压力模型

| 级别 | 条件 | 框架行为 | 建议 VM 行为 |
|------|------|---------|-------------|
| 0 (正常) | allocated < soft | 仅 minor GC on nursery full | 正常执行 |
| 1 (预警) | allocated ≥ soft | 增量回收 / 限速 | 限制分配速率 |
| 2 (危急) | allocated ≥ hard | 强制 full STW GC | GC 后仍超限 → OOM |

### 4.2 压力通知回调

```c
// gc_vm_hooks 中增加：
typedef struct gc_vm_hooks {
    gc_scan_roots_fn  scan_roots;
    void*             vm_ctx;
    // 新增：
    void (*on_pressure)(void* vm_ctx, int level);    // 压力变化通知
    void (*on_oom)(void* vm_ctx);                    // 无法恢复的 OOM
} gc_vm_hooks;
```

### 4.3 自适应触发策略

```c
// 每次 GC 后根据存活率调整下次触发阈值
void gc_adjust_trigger_after_collection(gc_runtime* rt) {
    size_t live = rt->stats.heap_live_bytes;
    int growth = rt->cfg.gc_growth_percent;  // 默认 100 (翻倍)
    rt->next_gc_trigger = live + live * growth / 100;
    if (rt->next_gc_trigger > rt->cfg.gc_threshold_hard) {
        rt->next_gc_trigger = rt->cfg.gc_threshold_hard;
    }
}
```

## 5. Benchmark 基础设施

### 5.1 计时工具

```c
// src/core/clock.c（新建）
#include <time.h>

double gc_clock_now_ms(void) {
    struct timespec ts;
    timespec_get(&ts, TIME_UTC);
    return (double)ts.tv_sec * 1000.0 + (double)ts.tv_nsec / 1000000.0;
}
```

### 5.2 输出格式标准

所有 benchmark 输出 key=value 格式，便于脚本解析：

```
benchmark=alloc_small
algorithm=gen-copy-ms
iterations=1000000
elapsed_ms=45.123
ns_per_op=45.12
ops_per_sec=22161234.56
peak_rss_kb=8192
minor_gc_count=12
minor_gc_total_ms=3.456
```

### 5.3 推荐 benchmark 矩阵

| Benchmark | 度量重点 | 对应优化 |
|-----------|---------|---------|
| `alloc_small` | 小对象分配速率 | bump-pointer / TLAB |
| `alloc_large` | 大对象分配路径 | LOS / malloc |
| `old_to_young_writes` | 写屏障 + minor GC | card_table / barrier |
| `full_collect_graph` | full GC 暂停时间 | mark 效率 / sweep 效率 |
| `nursery_churn` | 短命对象 GC 吞吐 | nursery size / copying |
| `cycle_detection` | 环回收延迟 | trial deletion 效率 |
| `concurrent_alloc` | 多线程分配竞争 | TLAB / 无锁 |
| `promotion_rate` | 晋升压力 | 晋升策略 / old gen 管理 |
