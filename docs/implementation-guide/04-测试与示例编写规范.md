# 04 — 测试与示例编写规范

> 指导如何为 xgc 编写单元测试、集成测试、示例程序和 benchmark。

---

## 1. 单元测试（substrate test）

### 1.1 目的

每个 `src/core/*.c` 中的 substrate 模块必须有独立的单元测试，**直接验证 substrate 自身的正确性**，不依赖任何具体算法。

### 1.2 文件命名

```
tests/test_<module>_substrate.c
```

### 1.3 完整模板

```c
#include "gc_internal.h"

#include <assert.h>
#include <stdlib.h>
#include <string.h>

/* ── 辅助 descriptor（大多数 substrate 测试都需要） ── */

static const gc_descriptor TEST_DESC = {
    .name              = "TestObject",
    .fixed_size        = sizeof(gc_header),
    .flags             = 0u,
    .kind              = 1u,
    .trace_slots       = NULL,
    .trace_slots_range = NULL,
    .trace_edges       = NULL,
    .finalize          = NULL,
};

/* ── 测试函数（每个以 test_ 开头，static） ── */

static void test_basic_functionality(void) {
    // 1. Setup: 创建被测 substrate 实例
    // 2. Exercise: 调用函数
    // 3. Assert: assert(condition)
    // 4. Teardown: 释放资源
}

static void test_edge_case(void) {
    // NULL 输入、溢出、空集合等
}

static void test_invariants_after_operations(void) {
    // 操作后调用 gc_*_check_invariants == 1
}

/* ── main ── */

int main(void) {
    test_basic_functionality();
    test_edge_case();
    test_invariants_after_operations();
    return EXIT_SUCCESS;
}
```

### 1.4 必须覆盖的场景

| 场景类型 | 说明 |
|---------|------|
| 正常路径 | 创建 → 操作 → 验证结果 |
| 空/NULL 输入 | 函数不崩溃（graceful no-op） |
| 边界条件 | 满容量、零容量、单元素 |
| 破坏后恢复 | 故意破坏状态 → invariant 检测到 → 修复 → invariant 通过 |
| 内存清理 | 所有 malloc 的内存最终 free（ASan 验证） |

### 1.5 注册到 CMake

```cmake
# cmake/tests.cmake
add_xgc_test(test_<module>_substrate ${XGC_PROJECT_ROOT}/tests/test_<module>_substrate.c)
```

## 2. 集成测试（smoke test）

### 2.1 目的

验证一个完整算法从创建到销毁的**端到端正确性**。

### 2.2 文件命名

```
tests/test_<algorithm>_smoke.c
```

### 2.3 完整模板

```c
#include "xgc/gc.h"
#include <assert.h>
#include <stdio.h>
#include <stdlib.h>

/* ── 测试用对象类型 ── */

typedef struct TestNode {
    gc_header         gc;
    struct TestNode*  left;
    struct TestNode*  right;
    int               id;
} TestNode;

/* ── 测试用 VM 状态 ── */

typedef struct {
    TestNode* roots[8];
    int       root_count;
    int       finalized_count;
} TestVm;

static TestVm* g_test_vm;

/* ── descriptor 回调 ── */

static void test_trace_slots(gc_header* obj, gc_visit_slot_fn visit_slot, void* ctx) {
    TestNode* node = (TestNode*)obj;
    if (node->left != NULL) {
        visit_slot((gc_header**)&node->left, ctx);
    }
    if (node->right != NULL) {
        visit_slot((gc_header**)&node->right, ctx);
    }
}

static void test_trace_slots_range(gc_header* obj, size_t byte_begin, size_t byte_end,
                                   gc_visit_slot_fn visit_slot, void* ctx) {
    TestNode* node = (TestNode*)obj;
    size_t left_offset  = offsetof(TestNode, left);
    size_t right_offset = offsetof(TestNode, right);
    if (byte_begin <= left_offset && left_offset < byte_end && node->left != NULL) {
        visit_slot((gc_header**)&node->left, ctx);
    }
    if (byte_begin <= right_offset && right_offset < byte_end && node->right != NULL) {
        visit_slot((gc_header**)&node->right, ctx);
    }
}

static void test_trace_edges(gc_header* obj, gc_visit_object_fn visit_obj, void* ctx) {
    TestNode* node = (TestNode*)obj;
    if (node->left != NULL) visit_obj((gc_header*)node->left, ctx);
    if (node->right != NULL) visit_obj((gc_header*)node->right, ctx);
}

static void counted_finalize(gc_header* obj) {
    (void)obj;
    if (g_test_vm) g_test_vm->finalized_count++;
}

/* ── descriptor 定义 ── */

static const gc_descriptor TEST_NODE_DESC = {
    .name              = "TestNode",
    .fixed_size        = sizeof(TestNode),
    .flags             = GC_DESC_FLAG_CONTAINS_REFS | GC_DESC_FLAG_HAS_FINALIZER,
    .kind              = 1,
    .trace_slots       = test_trace_slots,
    .trace_slots_range = test_trace_slots_range,
    .trace_edges       = test_trace_edges,
    .finalize          = counted_finalize,
};

/* ── 根扫描回调 ── */

static void test_scan_roots(void* vm_ctx, gc_visit_slot_fn visit_root_slot, void* ctx) {
    TestVm* vm = (TestVm*)vm_ctx;
    for (int i = 0; i < vm->root_count; ++i) {
        visit_root_slot((gc_header**)&vm->roots[i], ctx);
    }
}

/* ── 辅助：创建节点 ── */

static TestNode* make_node(gc_runtime* rt, gc_thread_context* thread, int id) {
    TestNode* node = (TestNode*)gc_alloc_typed(rt, thread, &TEST_NODE_DESC,
                                               sizeof(TestNode), GC_ALLOC_DEFAULT);
    assert(node != NULL);
    node->left = NULL;
    node->right = NULL;
    node->id = id;
    return node;
}

/* ── 测试场景 ── */

int main(void) {
    gc_config         cfg;
    gc_vm_hooks       hooks;
    gc_runtime*       rt;
    gc_thread_context* thread;
    TestVm            vm = {0};
    TestNode*         a;
    TestNode*         b;
    TestNode*         c;

    gc_config_init_default(&cfg);
    g_test_vm        = &vm;
    hooks.scan_roots = test_scan_roots;
    hooks.vm_ctx     = &vm;

    rt = gc_runtime_create(&cfg, xgc_default_algorithm(), &hooks);
    assert(rt != NULL);
    thread = gc_thread_attach(rt, &vm);
    assert(thread != NULL);

    /* ── Scenario 1: 可达对象不被回收 ── */
    a = make_node(rt, thread, 1);
    b = make_node(rt, thread, 2);
    c = make_node(rt, thread, 3);
    gc_store_ref(rt, thread, (gc_header*)a, (gc_header**)&a->left, (gc_header*)b);
    gc_store_ref(rt, thread, (gc_header*)b, (gc_header**)&b->left, (gc_header*)c);
    vm.roots[0] = a;
    vm.root_count = 1;

    gc_collect_full(rt);
    assert(gc_runtime_check_invariants(rt) == 1);
    assert(vm.finalized_count == 0);

    /* ── Scenario 2: 不可达对象被回收 ── */
    vm.roots[0] = NULL;
    vm.root_count = 0;
    gc_collect_full(rt);
    assert(vm.finalized_count == 3);
    assert(gc_runtime_check_invariants(rt) == 1);

    /* ── Scenario 3: 环引用被回收 ── */
    a = make_node(rt, thread, 4);
    b = make_node(rt, thread, 5);
    gc_store_ref(rt, thread, (gc_header*)a, (gc_header**)&a->left, (gc_header*)b);
    gc_store_ref(rt, thread, (gc_header*)b, (gc_header**)&b->left, (gc_header*)a);
    gc_collect_full(rt);
    assert(vm.finalized_count == 5);

    /* ── Scenario 4: handle 保护对象 ── */
    a = make_node(rt, thread, 6);
    gc_handle* h = gc_handle_acquire(rt, (gc_header*)a, GC_HANDLE_PINNED);
    gc_collect_full(rt);
    assert(vm.finalized_count == 5);  // a 没死
    gc_handle_release(h);
    gc_collect_full(rt);
    assert(vm.finalized_count == 6);  // a 死了

    /* ── 清理 ── */
    gc_thread_detach(thread);
    gc_runtime_destroy(rt);
    printf("%s smoke test passed\n", xgc_default_algorithm()->name);
    return EXIT_SUCCESS;
}
```

### 2.4 必须覆盖的场景

| # | 场景 | 验证 |
|---|------|------|
| 1 | 可达对象存活 | `finalized_count == 0` |
| 2 | 不可达对象被回收 | `finalized_count == N` |
| 3 | 环引用被回收 | `finalized_count` 增加 |
| 4 | handle 保护对象 | 持有 handle 时不回收，释放后回收 |
| 5 | invariant 检查 | 每个关键步骤后 `gc_runtime_check_invariants(rt) == 1` |

## 3. 示例程序

### 3.1 目的

演示 VM 如何正确接入 xgc。面向**用户**而非框架开发者。

### 3.2 文件命名

```
examples/<algorithm>_demo.c
```

### 3.3 结构规范

```c
#include "xgc/gc.h"       // ← 只用公共头，不用 gc_internal.h
#include <stdio.h>
#include <stdlib.h>

// 1. 定义用户对象类型（gc_header 作为第一个成员）
// 2. 实现 descriptor 回调
// 3. 实现 scan_roots 回调
// 4. main() 中演示完整生命周期：
//    - gc_config_init_default
//    - gc_runtime_create
//    - gc_thread_attach
//    - 分配 + 写引用 + 收集
//    - gc_thread_detach
//    - gc_runtime_destroy
// 5. 用 printf 输出可观察行为（如 finalize 被调用）
```

### 3.4 CMake 注册

```cmake
# cmake/examples.cmake
add_xgc_example(<algo>_demo ${XGC_PROJECT_ROOT}/examples/<algo>_demo.c)
```

## 4. Benchmark

### 4.1 目的

度量 GC 子系统在特定负载下的性能特征。

### 4.2 文件命名

```
bench/<workload>.c
```

### 4.3 结构规范

```c
#include "xgc/gc.h"
#include <time.h>
#include <stdio.h>

// 1. 定义 benchmark 用对象（通常很简单 — header + payload）
// 2. 定义 descriptor（trace_slots_range 如果涉及 barrier scan）
// 3. main(argc, argv):
//    - 解析参数（iterations, 间隔等）
//    - gc_runtime_create
//    - gc_thread_attach
//    - 计时开始
//    - 核心循环（分配/写入/触发GC）
//    - 计时结束
//    - 输出 key=value 格式指标
//    - 清理

// 输出格式：
//   benchmark=<name>
//   algorithm=<algo_name>
//   iterations=<N>
//   elapsed_ms=<X.XXX>
//   ns_per_op=<X.XX>
//   ops_per_sec=<X.XX>
```

### 4.4 CMake 注册

```cmake
# cmake/benchmarks.cmake
add_xgc_benchmark(bench_<workload> ${XGC_PROJECT_ROOT}/bench/<workload>.c)
```

### 4.5 当前已有 benchmark

| 文件 | 度量 |
|------|------|
| `bench/old_to_young_writes.c` | 老→年轻 slot 写入 + minor GC 的吞吐与延迟 |
| `bench/alloc_small.c` | 小对象连续分配速率 |

### 4.6 推荐新增 benchmark

| Benchmark | 度量 |
|-----------|------|
| `bench/full_collect_graph.c` | 构建大对象图 → full GC → 度量暂停时间 |
| `bench/cycle_detection.c` | 创建大量环 → bacon-rajan collect → 度量环回收效率 |
| `bench/nursery_churn.c` | 大量短命对象 → minor GC → 度量年轻代吞吐 |

## 5. 新增一个完整算法的 Checklist

```
□ 1. 创建 src/algo/<name>/ 目录
□ 2. 实现 vtable（至少 alloc + collect_full）
□ 3. 声明正确的 caps
□ 4. 在 gc_algorithm.h 中增加工厂函数声明
□ 5. 在算法入口文件中实现工厂函数 + xgc_default_algorithm()
□ 6. 在 CMakeLists.txt set_property(CACHE GC_ALGORITHM ...) 中加入选项
□ 7. 编写 tests/test_<name>_smoke.c
□ 8. 在 cmake/tests.cmake 中条件注册
□ 9. 编写 examples/<name>_demo.c
□ 10. 在 cmake/examples.cmake 中注册
□ 11. 验证全通过：
       cmake -B build -DGC_ALGORITHM=<name> -DCMAKE_BUILD_TYPE=Debug
       cmake --build build && ctest --test-dir build
□ 12. ASan 验证：
       cmake -B build-asan -DGC_ALGORITHM=<name> -DSAN_ADDRESS=ON
       cmake --build build-asan && ctest --test-dir build-asan
□ 13. 更新 docs/ 中的算法清单
```
